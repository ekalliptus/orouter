# Rencana deploy VPS native Rust + merge/push

Asumsi default karena detail VPS belum diberikan: **Ubuntu/Debian + systemd + Caddy**, Rust update **check setiap deploy, update hanya saat `UPDATE_RUST=1`**.

## 1. Jadikan release benar-benar standalone

### Rust melayani React static
- Tambah `tower-http` file serving.
- `STATIC_DIR` env, default sesuai development/release.
- `/`, asset Vite, favicon, i18n → static files.
- Unknown frontend route → `index.html` untuk React Router SPA.
- Unknown `/api/*` dan `/v1/*` tetap JSON 404, bukan HTML SPA.
- Hasil: satu proses Rust. Caddy hanya TLS/reverse proxy, bukan app runtime.

### Production assets
- Tambah script kecil `react-web/scripts/sync-public.mjs` untuk menyalin `public/i18n/literals/*` lama ke build Vite.
- Jalankan otomatis pada `predev` dan `prebuild`.
- Hapus Vite dev proxy `/i18n` yang salah mengirim translation files ke backend.

### Systemd-safe shutdown
- Tangani SIGTERM + SIGINT.
- Gunakan graceful shutdown Axum.
- `TimeoutStopSec` systemd membatasi shutdown SSE lama.

## 2. Toolchain Rust VPS

Tambah `rust-toolchain.toml`:
- channel `stable`
- profile `minimal`
- component `rustfmt`

Deploy script:
- Jika `rustup` belum ada: install rustup stable minimal untuk user deploy.
- Setiap deploy: `rustup check` + tampilkan versi `rustc/cargo`.
- Default tidak mengubah compiler.
- `UPDATE_RUST=1 ./scripts/vps-native.sh deploy` menjalankan `rustup update stable` sebelum test/build.
- Subcommand eksplisit: `rust-check`, `rust-update`.

## 3. Native VPS release files

Buat:
- `deploy/orouter.service`
  - runtime user `orouter`
  - `/opt/orouter/current/orouter-backend`
  - env `/etc/orouter/orouter.env`
  - state `/var/lib/9router`
  - restart on failure, journald, hardening dasar
- `deploy/orouter.env.example`
  - `DATA_DIR=/var/lib/9router`
  - `RUST_HOST=127.0.0.1`, `RUST_PORT=20130`
  - `STATIC_DIR=/opt/orouter/current/web`
  - JWT/password/security variables
- `deploy/Caddyfile.example`
  - HTTPS/TLS otomatis
  - `reverse_proxy 127.0.0.1:20130`
  - SSE flush langsung

## 4. Satu script VPS

Buat `scripts/vps-native.sh` dengan subcommand:

```bash
./scripts/vps-native.sh bootstrap
./scripts/vps-native.sh deploy
./scripts/vps-native.sh status
./scripts/vps-native.sh logs
./scripts/vps-native.sh rust-check
./scripts/vps-native.sh rust-update
./scripts/vps-native.sh rollback
```

### `bootstrap`
- Validasi Ubuntu/Debian.
- Install `curl`, `ca-certificates`, `build-essential`, `sqlite3` via apt.
- Install Rust/Bun jika belum ada.
- Buat user runtime `orouter`, `/opt/orouter/releases`, `/var/lib/9router`, `/etc/orouter`.
- Generate `/etc/orouter/orouter.env` pertama kali dengan JWT secret + password acak; tampilkan password sekali.
- Install/enable systemd unit.

### `deploy`
1. `rustup check`; optional update via `UPDATE_RUST=1`.
2. `cargo fmt --check`, `cargo test --locked`, `cargo build --release --locked`.
3. `bun install --frozen-lockfile`, `bun run build`.
4. Backup SQLite via `sqlite3 .backup` bila DB ada.
5. Copy binary + React dist ke `/opt/orouter/releases/<git-sha>/`.
6. Atomic symlink `/opt/orouter/current`.
7. Restart systemd.
8. Probe `/health`.
9. Bila gagal: kembalikan symlink sebelumnya, restart, probe ulang.

Tidak auto-delete release lama.

## 5. Dokumentasi/env/root scripts
- Tambah root commands `build:rewrite`, `test:rewrite` bila berguna.
- Tambah Rust production vars ke `.env.example`.
- Tambah bagian README: first deploy, normal update, opt-in Rust update, status/logs, Caddy, rollback.
- Tegaskan Dockerfile lama masih legacy Go/Next; native VPS adalah deployment resmi rewrite saat ini.

## 6. Verifikasi lokal
- Rust `cargo fmt --check`, tests, release build.
- React TypeScript + production build.
- Jalankan release binary dengan `STATIC_DIR=react-web/dist`.
- Curl `/`, SPA route, `/health`, unknown `/api` 404.
- Fresh `DATA_DIR` smoke test.
- Shell syntax check deploy script.

## 7. Git
1. Commit deployment support di `rewrite/rust-react-kiddraw`.
2. `git fetch origin` dan pastikan `origin/main` belum bergerak.
3. Fast-forward merge branch ke local `main` (`git merge --ff-only`).
4. Push `main` ke `origin`.
5. Artifact `.zcode/plans/...` tetap tidak di-commit.

## 8. VPS aktual
Repo akan punya script siap jalan. Saya tidak akan SSH tanpa host/user/key. Setelah push, perintah awal di VPS:

```bash
git pull origin main
./scripts/vps-native.sh bootstrap
./scripts/vps-native.sh deploy
```

Update biasa:

```bash
git pull origin main
./scripts/vps-native.sh deploy
```

Update Rust sekaligus:

```bash
git pull origin main
UPDATE_RUST=1 ./scripts/vps-native.sh deploy
```
