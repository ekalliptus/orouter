## Target
Ringankan dashboard tanpa mengubah fitur, data, urutan provider, atau alur navigasi. First pass: hapus kerja render/network berulang; pertahankan tampilan topology.

## Perubahan
1. **Dashboard shell**
   - Hapus `key={pathname}` pada Header agar tidak remount dan refetch auth tiap navigasi.
   - Hilangkan backdrop blur hanya pada header permanen; warna, border, shadow tetap.

2. **Cache provider terpusat**
   - Perluas `src/store/providerStore.js` dengan cache provider nodes, TTL, invalidation, serta in-flight promise deduplication.
   - Migrasikan `UsageStats` dan Providers page ke store yang sama.
   - Pertahankan fetch fresh pada detail/mutation-sensitive flow.
   - Perbaiki helper cache agar menerima `id` maupun `_id`.

3. **Providers page CPU**
   - Hitung status/statistik connection sekali dalam `useMemo` dan `Map`.
   - Memoize filter/sort/search-derived lists.
   - Pertahankan prioritas, status badge, error terbaru, pencarian, serta batas 20 API-key card.

4. **Usage page rerender**
   - Ganti timer per row menjadi satu timer milik RecentRequests.
   - Tambahkan abort/stale-response guard saat period berubah.
   - Abaikan SSE payload identik melalui signature ringan; update valid tetap realtime.

5. **ProviderTopology**
   - Ganti interval render satu detik dengan satu timeout pada expiry aktif terdekat.
   - Hoist opsi xyflow statis.
   - Debounce ResizeObserver lewat `requestAnimationFrame`.
   - Animasi/partikel/warna tetap pada first pass; evaluasi pengurangan hanya bila profiling masih berat.

## Verifikasi
- Jalankan `npx react-doctor@latest --verbose --scope changed`.
- Jalankan `bun run build`.
- Browser smoke check: navigasi Header, auth status, provider search/order/toggle, Usage period switching, SSE active/recent/error, topology expiry/resize.
- Ukur Network: Usage lalu Providers maksimal satu fetch provider dan satu provider-node dalam TTL.
- Ukur Performance/React Profiler: satu timer RecentRequests, tidak ada Header remount, topology tidak rerender tiap detik.

## Batasan
- Tidak menambah dependency.
- Tidak mengganti xyflow/recharts pada first pass.
- Tidak commit/push sebelum hasil diverifikasi dan dilaporkan.
